# DropX logo assets

- `dropx-mark.svg` — small mark for avatars, favicons, app icons, and compact navigation.
- `dropx-mark-mono-black.svg` — one-color mark for light print or constrained production.
- `dropx-mark-mono-white.svg` — one-color mark for dark print or constrained production.
- `dropx-wordmark-light.svg` — horizontal lockup for light backgrounds.
- `dropx-wordmark-dark.svg` — horizontal lockup for dark backgrounds.
- `dropx-lockup-light.svg` — large display lockup with descriptor for light backgrounds.
- `dropx-lockup-dark.svg` — large display lockup with descriptor for dark backgrounds.

Keep the original aspect ratio and preserve clear space equal to the height of the orange mark. Do not recolor, stretch, rotate, or add effects to the assets. Wordmark SVGs use the Inter font family; for print or vendor handoff, convert the wordmark text to outlines in the source design file before export.
