# DropX logo assets

- `dropx-mark.svg` — small mark for avatars, favicons, app icons, and compact navigation.
- `dropx-mark-mono-black.svg` — one-color mark for light print or constrained production.
- `dropx-mark-mono-white.svg` — one-color mark for dark print or constrained production.
- `dropx-favicon.svg` — 32px browser favicon; use the mark only, never a wordmark.
- `dropx-social-avatar.svg` — square avatar for social profiles and app stores.
- `dropx-wordmark-light.svg` — horizontal lockup for light backgrounds.
- `dropx-wordmark-dark.svg` — horizontal lockup for dark backgrounds.
- `dropx-wordmark-only-light.svg` — DropX name only for light backgrounds when the symbol is already present nearby.
- `dropx-wordmark-only-dark.svg` — DropX name only for dark backgrounds when the symbol is already present nearby.
- `dropx-wordmark-mono-black.svg` — one-color wordmark for light production.
- `dropx-wordmark-mono-white.svg` — one-color wordmark for dark production.
- `dropx-lockup-light.svg` — large display lockup with descriptor for light backgrounds.
- `dropx-lockup-dark.svg` — large display lockup with descriptor for dark backgrounds.
- `dropx-stack-light.svg` — centered stacked lockup for posters, presentations, and cover art on light backgrounds.
- `dropx-stack-dark.svg` — centered stacked lockup for posters, presentations, and cover art on dark backgrounds.
- `dropx-email-signature-light.svg` — compact horizontal lockup for email signatures and partner documents.

Keep the original aspect ratio and preserve clear space equal to the height of the orange mark. Do not recolor, stretch, rotate, or add effects to the assets. Wordmark SVGs use the Inter font family; for print or vendor handoff, convert the wordmark text to outlines in the source design file before export.

## Selection guide

| Need | Use |
| --- | --- |
| App header or website navigation | `dropx-wordmark-light.svg` or `dropx-wordmark-dark.svg` |
| Small screen, avatar, favicon, or app icon | `dropx-mark.svg` or `dropx-favicon.svg` |
| Social profile or app store tile | `dropx-social-avatar.svg` |
| Campaign hero, poster, or presentation cover | `dropx-lockup-*.svg` or `dropx-stack-*.svg` |
| Email signature or partner document | `dropx-email-signature-light.svg` |
| One-color print or engraving | `dropx-mark-mono-*.svg` or `dropx-wordmark-mono-*.svg` |
| The symbol is already visible nearby | `dropx-wordmark-only-*.svg` |

## Rules

- Use the full lockup when the audience may not know DropX yet.
- Use the mark alone only when space is tight or the surrounding context already identifies DropX.
- Never combine the mark with the wordmark manually; use an approved lockup.
- Never use the descriptor at small sizes where it becomes unreadable.
- Preserve the original aspect ratio and clear space on every surface.
